# 仓库说明写给谁

**README 帮使用者上手；AGENTS.md 帮编程代理在这个仓库里正确工作。** 同一事实在一个地方完整维护，另一处只在读者需要时给出链接。用户指定了位置时，遵循该要求。

## README：从用途到第一次使用

先说明项目解决什么问题，再给出实际支持的安装方式、最短可用示例和下一步阅读入口。许可证、贡献流程或变更记录已有独立文件时，直接链接。使用 GitHub Flavored Markdown；提示块留给确实影响操作的重要说明。

## AGENTS.md：让约束在正确范围生效

写清仓库特有、会改变代理行动的条件，例如在哪个目录执行哪项检查、改动某个模块时遵守什么边界。全仓约束放根目录；子项目确有不同的命令或规则时，再就近补充。

命令和路径从清单、脚本或 CI 核对，限定适用的目录、版本和环境。引用仓库已配置的命令和声明命令已运行成功是两件事，后者要有执行结果。
