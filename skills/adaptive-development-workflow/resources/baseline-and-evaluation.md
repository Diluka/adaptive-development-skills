# 行为基线与评估方法分流

Use when 目标缺少简单唯一断言，需要判断应保护可稳定重放的现有行为，还是评价主观、多解或概率性能力。

| 结果形状 | 方法 |
|---|---|
| 现有或复杂行为可从真实入口稳定重放，目标是发现改动前后漂移 | 特征化 / 黄金主 / 批准测试（Characterization / Golden Master / Approval Testing） |
| 结果有多种合理答案，质量主观或执行具有概率性，目标是定义并持续改进能力 | 评估驱动开发（Eval-Driven Development） |
| 简单确定性行为已有独立稳定判据 | 不使用本资源，直接用明确断言或属性验证 |
| 连什么输出、任务或评价依据能够区分结果都未知 | 先用未知探索（Unknown Exploration）调查 |

当前行为、一次候选输出或一次模型评分都不自动成为正确目标。两个结果形状同时存在时，按独立产物和反证边界拆成有依赖的工作单元，再分别使用对应方法；不要因为都需要“比较基线”就把它们合成一个循环。

两种方法产生的都是证据，不自动成为确定性产品契约；证据独立性、复用、失效和长期收敛统一见 [evidence.md](evidence.md)。
