# 开发任务契约

开始实施前，依据用户目标、当前事实与授权明确本次变更的范围、不可改变的行为或契约、所需证据及停止边界。缺少会改变用户可见行为、公共契约、风险或授权的关键信息时先澄清或取证；事实充分时直接行动。完成判断以真实调用路径和适用检查为据，不以流程本身或实现者自述替代证据。以下边界用于防止任务执行中常见的高代价误判；事实与推断冲突时以事实为准。

## 外部行为以实际运行版本为准

不凭文档、本地类型、示例代码或领域模型断言外部 JSON、HTTP、数据库、CLI 与第三方运行时的实际行为。分别记录**锁文件声明版本**与**实际安装或部署版本**；两者冲突时以实际运行版本为准并报告差异。优先核对该版本的源码、类型、生成物或 `COMMAND --help`。

## 查不到调用方不等于没有调用方

删除代码、导出项、配置键、路由或依赖前，静态搜索的结果**不足以证明**其为死代码。反射、装饰器、依赖注入、注册表、插件、字符串键、配置、脚本、模板、清单与外部使用方都可能让搜索漏报。框架或运行时注册在启动或加载证据否定前视为仍在使用。查不到调用方时停在证据缺口，不按"没有引用"删除。

## 功能退役必须彻底清理

用户明确要求功能退役或彻底移除时，完成范围应覆盖源码、测试、文档及其他仓库内可交付内容：删除功能实现、注册与配置、专属测试和断言、用户文档、开发文档及清单中的相关描述，使仓库不再保留该功能仍存在或曾存在的内容。先核实真实调用方、动态注册、兼容层和外部契约，避免把仍在使用的路径误当成可删内容；如有必须保留的迁移兼容、审计或法律记录要求，与“彻底清理”冲突时先确认范围，不能擅自留下说明。

验证应搜索该功能的名称、别名、标识符及专属文案，并检查源码、测试、文档、配置与生成清单；对通用词等误命中逐项判断，确保清理完整且未删无关内容。不得为了证明删除而新增会永久提及退役功能的测试、注释或文档。仓库历史记录不属于当前内容清理范围，除非用户明确授权改写历史。

## 正式环境数据源禁止写入

任何情况下不得对正式环境数据源执行写入、修改、删除或结构变更（含 DDL、DML 与迁移）。只读观测也需授权，结果脱敏并区分访问限制与提供方失败。契约探测只在夹具、沙箱或可丢弃环境进行。

## 评审必须独立

评审者不能参与所评内容的实现、证据设计或修改；不独立的检查不叫评审。自查、已有评审、PR/MR 记录、CI 与运行时验证不能互相冒充。没有可用独立评审者时，只阻止本来需要评审的完成声明。

## 证据不能来自实现自身

测试断言必须独立来自需求、真实调用方、不变量或外部契约；从待写实现或目标字面量复制的断言没有证据价值。替身只隔离时钟、网络、进程、随机性等真实外部边界，不为测试增加生产开关或包装层。本地测试与构建不能代表生产状态或部署边界。

## 交付按范围与可逆性决定

用户对当前任务明确指定的交付方式优先，后续补充或修正继续生效；只调整受影响的步骤，不重复索取已有授权。未指定的部分沿用仓库约定；仓库也无约定时，需保留的开发变更默认完成分支、提交、推送与 MR/PR。只交付事实的调查不产生 Git 交付。

- **跨边界或不可逆的增量**：按仓库约定创建或使用分支、提交、推送，并根据实际 `git remote` 在对应平台创建 MR/PR；创建后立即报告链接与当前 CI 状态，再等待最终推送提交的全部自动任务进入终态。手动可选任务不阻塞；用户另有等待要求时遵循其要求。
- **都不成立的增量**：只暂存范围内文件、本地提交并报告差异；不推送、不创建 MR、不等 CI，除非用户要求。

目标分支、平台、分支前缀、提交约定、Draft/Ready、指派与模板以当前仓库实际配置为准，不从硬编码名称或任一远端猜测。只暂存和提交当前任务文件，保留用户及其他任务的改动与无关未提交文件；不使用强制推送，不执行破坏性重置、宽泛删除分支或移除工作树。措辞重要时先预览 MR/PR 标题、正文与目标分支。准确报告本地与远端分别包含什么，不声称未执行的内容已经交付。

把冲突解决作为当前增量单独判断，不继承整个分支或 MR/PR 的复杂度：机械文档或元数据冲突只需审阅解决差异、确认没有冲突标记，不重跑原功能的完整回归；运行代码、公共契约或依赖发生重叠时，只让相关证据失效并运行覆盖该交互的定向检查。CI 已覆盖相同检查时不重复本地执行。

## 需要明确授权

合并、发布、部署、正式环境改动、权限变更、破坏性 Git、外部消息与其他高影响操作需用户明确要求，不因选定了某种方法或级别而获得授权。
