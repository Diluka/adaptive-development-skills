# 发起独立评审

## 适用范围

- 复杂或高风险开发增量需要最终独立评审。
- 常规增量存在定向验证无法覆盖的已识别风险。
- 复杂非开发调研需要独立检查偏航、反证或结论。

评审者独立于相关实现、证据设计和差异修改。本技能只负责准备与发起评审；简单变更和已由有效独立评审覆盖的相同差异不重复评审。

## 准备证据包

找到实际目标分支基点，并包含全部提交、未暂存、已暂存和未跟踪内容：

```bash
git merge-base HEAD <target-branch>
git log --oneline <base>..HEAD
git diff --find-renames -U10 <base>..HEAD
git status --short --untracked-files=all
git diff
git diff --cached
```

没有 `HEAD` 时，以空树为基准。未跟踪文件用 `git diff --no-index -- /dev/null <path>` 单独生成差异，不为评审暂存文件。

证据包包含：

- 原始需求、选定设计与明确不变量；
- 实际基点、完整差异和受影响的真实调用路径；
- 最新验证、已知基线失败和仍未证明的具体风险。

## 请求评审

要求评审者读取证据包和完整实际差异，按严重性报告带文件与行号的发现。评审范围是实现是否满足原始需求和选定设计、是否在真实调用路径产生回归，以及证据包列出的风险是否仍未覆盖；通用可能性不构成新增产品需求。

评审者保持只读，不修改差异、计划或任务范围。协调者逐条核验发现；实质修复后重新验证受影响范围，并仅在原评审结论或风险面改变时安排复审。

复杂非开发调研的证据包改为原始目标、范围、证据、反证、结论和未决项，不需要 Git 差异。
