# 验证既有契约

## 核心原则

以实际版本、调用方和输入输出核验运行边界。版本未知先确认；类型、示例、模拟和可信内部类型都不能证明外部契约。本技能只交付事实，不定义新契约或实施正式变更。

## 记录最小证据

| 字段 | 证据 |
|---|---|
| 使用方 | 当前生产调用位置和输入结构 |
| 提供方 | 包、服务、CLI 或框架名称 |
| 版本 | 锁文件声明版本与实际安装/部署版本分开记录 |
| 探测环境 | OS、运行时、部署目标；结论只覆盖该环境，跨环境需重测 |
| 契约 | 类型，以及运行时源码、帮助信息或传输行为 |
| 失败 | 精确错误、响应、序列化结果或状态转换 |
| 安全探测 | 本地夹具、沙箱、只读请求或可丢弃环境 |

本地类型、生成声明和领域模型只表达当前代码期望，不能证明外部 JSON、HTTP、数据库、CLI 或第三方运行时；[execution](../execution/SKILL.md) 的 `resources/type-driven-design.md` 所建可信表示在进入前仍须核验边界。

## 核验既有边界

开始前仅用当前上下文（包括同一会话）盘点已有的调用方、版本、输入、环境与边界证据，写出仍待核实的契约缺口，以及哪种结果会改变当前回答；盘点本身不重新追踪入口或读取来源。这些条件未变，且证据已经直接回答原问题或通过已确认不变量足以可靠推出答案时，复用证据并直接报告。用户明确要求当前读回、重新运行或独立来源时，只取得该目标所需的新观测。

仍有契约缺口，或用户明确要求当前边界观测时，才从真实入口追到边界，依次核对锁定/解析版本、该版本源码/类型/生成物或 `COMMAND --help`，再做最小安全探测。每项新增核验都对应一个仍可能改变结论的缺口或明确要求的产物；两者都不存在时结束。锁文件声明版本与实际安装版本分开记录，不一致时以实际安装/部署版本为准，并报告差异来源（手动安装、间接依赖、平台差异等）；文档与项目版本冲突时同样以实际安装或部署产物为准。

服务于 [unknown-exploration](../unknown-exploration/SKILL.md) 时，把版本和探测证据返回探索，不擅自进入正式实现。没有外部或框架边界时，结束本调查单元并返回 [adaptive-development-workflow](../adaptive-development-workflow/SKILL.md) 重新分类。

## 契约版本迁移影响

对比目标版本与当前版本的契约差异（发布说明、changelog、类型或传输变化、破坏性变更），把迁移影响面作为可交付事实之一。本技能只交付迁移影响事实，不实施升级；需要正式迁移时返回 Workflow 建立开发单元，再由 Execution 选择实施方法。

## 方法边界与衔接

本技能只回答既有边界当前是什么。目标若变为新增或演进消费者期望、契约产物、提供者验证和兼容部署决定，当前调查已结束；把双方控制关系、版本与边界事实返回 Workflow 建立开发单元，再由 Execution 选法。不要用当前行为探测代替持续契约开发。

需要把已核实契约转为正式实现、长期回归测试或契约产物时，停止调查。把确切版本、调用链、观察结果和未决边界返回 [adaptive-development-workflow](../adaptive-development-workflow/SKILL.md) 建立开发单元，再由 [execution](../execution/SKILL.md) 选择开发方式和证据；本技能不修改实现或新增正式测试。

## 安全边界

- 正式环境仅在授权下只读；脱敏捕获结果并区分访问限制与提供方失败；无调用方和契约证据不增兼容分支。

完成时报告确切版本、调用链、观察到的契约、探测结果和仍未验证的边界。
