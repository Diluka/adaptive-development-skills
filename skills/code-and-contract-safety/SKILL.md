# 代码与契约安全

本技能记录静态搜索与常识推断的适用边界；关键结论以核实事实为准。

## 依据实际运行版本核验外部行为

以真实调用方和运行版本对应的契约证据核验外部 JSON、HTTP、数据库、CLI 与第三方运行时行为。分别记录**锁文件声明版本**与**实际安装或部署版本**；存在差异时以实际运行版本为准并报告差异。优先核对该版本的源码、类型、生成物或 `COMMAND --help`。

## 综合证据确认调用方

删除代码、导出项、配置键、路由或依赖前，结合静态搜索、反射、装饰器、依赖注入、注册表、插件、字符串键、配置、脚本、模板、清单与外部使用方等证据判断使用情况。框架或运行时注册以启动或加载证据核实。静态搜索未发现调用方时，继续核验动态调用路径并保留待确认项；证据充分后再决定是否删除。

## 正式环境数据源保持只读

开发、审查与验证期间，正式环境数据源保持只读，结构保持不变；任何写入、修改、删除或结构变更（含 DDL、DML 与迁移）均禁止。只读观测也需授权，结果应脱敏并区分访问限制与提供方失败。契约探测在夹具、沙箱或可丢弃环境进行。

## 评审保持独立

评审者与所评内容的实现、证据设计和修改环节保持独立。自查、已有评审、PR/MR 记录、CI 与运行时验证分别提供各自范围内的证据。需要独立评审的工作，在独立评审完成后再作相应完成声明。

## 证据独立于实现

测试断言依据需求、真实调用方、不变量或外部契约独立建立，并与待写实现和目标字面量保持独立。替身隔离时钟、网络、进程、随机性等真实外部边界；生产逻辑保持与测试替身分离。本地测试与构建提供本地执行证据，生产状态或部署边界由对应环境证据确认。

## 高影响操作遵循明确授权

合并、发布、部署、权限变更、破坏性 Git、外部消息与其他高影响操作需用户明确要求。高风险或难回退的新动作先确认并说明回退或恢复路径；正式环境数据源在所有情况下保持只读。
