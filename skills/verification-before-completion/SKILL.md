# 完成前核验：声明只到证据为止

本技能只核对最终声明与仍适用的直接证据；过程中的手段选择由 [execution](../execution/SKILL.md) 承担。“最新”指输入、环境、版本、调用路径和风险面仍与结论相符，不要求重复运行未失效的检查。证据充分后停止追加；缺口尚在时收窄声明或补能拒绝当前合理错误的观测。

## 最终增量与证据

1. 对照原始请求和已确认的纠正，检查任务基线以来的完整实际差异（实现、测试、文档及相关日志），清除依赖旧假设的残留，确认改动属于授权范围或必要依赖。
2. 用真实消费或激活路径的直接观测覆盖用户明确要求的正常场景，并完成本仓库对当前增量的强制检查；额外测试、构建、类型检查或独立评审只补尚未证明的具体风险。
3. 对每条完成声明核对证据的输入、环境、版本、调用路径及适用风险。测试与构建只能证明覆盖的性质，不能证明被替身跳过的框架、传输、持久化或部署边界；只使受新改动影响的既有证据失效。证据复用与冲突处理见 [execution](../execution/SKILL.md) 的 `resources/evidence.md`。
4. 核对本次变更直接影响的既有说明、示例或导航；从现有路径追踪受影响内容，不开展全仓资料清扫。区分实际回归与已确认的基线失败。

| 要声明的结果 | 不可省略的对应证据 |
|---|---|
| 缺陷已修复 | 修复前症状或根因，加当前真实接缝的预期行为与相关正常路径 |
| 行为保持或安全清理 | 修改前后同一真实入口、条件与输入的核心结果对照；动态调用方与保留路径核验 |
| 外部集成可用 | 实际安装 / 部署版本与边界契约或安全集成探测 |
| 主观或概率能力改善 | 代表任务、预先确定的评价标准、重复或独立评估及已知波动 |
| 最终 CI 已结束 | 最终推送提交或合并结果的全部自动任务进入成功、失败或取消终态；自动触发的 review 环境任务参与等待，手动可选任务不阻塞 |
| 生产事故已解决 | 当前部署版本及改动后只读日志、指标或真实用户路径；本地测试不代表生产状态 |
| 软件可发布 | 最终集成结果的 CI、可追溯候选制品、同一制品的环境提升方案及当前恢复准备；没有发布授权时只报告就绪状态 |
| 已受控暴露 | 精确制品与配置、各暴露阶段的实时健康与业务观测、阈值决策、最终状态，以及实际回退结果或当前回退能力 |
| 调查已完成 | 原目标、可追溯事实与结论、剩余未知及临时产物边界 |

无法安全复现旧失败时复用有效的旧失败或根因证据，再在当前真实链路验证，不为证明修复而破坏工作区或正式环境。独立评审是否适用按当前风险判断；适用时由 [requesting-code-review](../requesting-code-review/SKILL.md) 取得独立于实现和证据设计的评审，只让结论或风险面因实质修改而改变的部分失效。

技能、提示规则与代理工作流是启发式产物：格式和引用检查只能证明结构有效；一次子代理模拟不是隔离行为实验。用代表任务说明覆盖边界，并以安装后的真实表现继续校准，不能声称静态检查证明“代理一定选对方法”。正式环境数据源不得在核验时写入。

报告实际观测或命令、结果、所支持的声明和未覆盖风险；没有跑到的检查或未终结的 CI 如实标为缺口。
